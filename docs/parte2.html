2  Regresión Polinomial

2.1 Objetivos

  • Ajustar un modelo de regresión polinomial usando la base de polinomios ortogonales, replicando en Python el comportamiento de la función poly() de R.
  • Construir e interpretar bandas de confianza puntuales para la curva ajustada.
  • Comparar dos estrategias para elegir el grado del polinomio: la prueba F de modelos anidados (enfoque clásico) y la validación cruzada de \(k\) particiones (enfoque moderno).
  • Extender la regresión polinomial al caso de una respuesta binaria mediante regresión logística.
  • Reconocer y evitar un error común de programación en Python relacionado con la reutilización de nombres de variables.
Nota

Esta práctica corresponde a la primera parte de la sección 7.8 del libro base con algunas modificaciones.

Código 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.api as sm

from ISLP import load_data
from ISLP.models import ModelSpec as MS, poly, summarize
Importante¿Por qué usamos ISLP.models y no una fórmula tipo la que vieron en R?

En R, la función poly(age, 4) dentro de una fórmula (wage ~ poly(age, 4)) construye automáticamente una base de polinomios ortogonales. En Python, el motor de fórmulas que usa statsmodels.formula.api (llamado patsy) no tiene una función poly() incorporada. Si se intenta escribir smf.ols('wage ~ poly(age, 4)', data=wage), Python buscará algún objeto llamado poly en el espacio de nombres disponible; si por accidente existe una variable u objeto distinto con ese mismo nombre (por ejemplo, si en algún momento se usó poly como nombre de una variable de scikit-learn), el resultado son errores confusos y difíciles de depurar.

Por esta razón, en esta práctica usamos la clase ModelSpec (importada aquí como MS) junto con la función poly que provee el propio paquete ISLP.

2.3 Ajuste de una regresión polinomial de grado 4

Construimos la matriz de diseño con una base de polinomios ortogonales de grado 4 sobre age, y ajustamos el modelo por mínimos cuadrados ordinarios.

Código 
design_g4 = MS([poly('age', degree=4)])
X_g4 = design_g4.fit_transform(wage)  # matriz de diseño (incluye intercepto)
y = wage['wage']

modelo_g4 = sm.OLS(y, X_g4).fit()
summarize(modelo_g4)

Tip

Los coeficientes que aparecen en la tabla no se interpretan uno por uno como en una regresión lineal simple (no se puede decir “por cada unidad que aumenta age…”), porque age entra al modelo a través de varias funciones base ortogonales simultáneamente. Lo que sí es directamente interpretable y útil es la curva ajustada completa \(\hat f(x_0)\), que construimos a continuación.

2.4 Curva ajustada y banda de confianza puntual

Código 
age_grid = np.linspace(wage['age'].min(), wage['age'].max(), 200)
datos_pred = pd.DataFrame({'age': age_grid})

# design_g4 ya quedó "ajustado" (fit) al llamar fit_transform sobre wage;
# ahora solo transformamos los datos nuevos con la MISMA base ortogonal.

X_pred = design_g4.transform(datos_pred)

prediccion = modelo_g4.get_prediction(X_pred)
resumen_pred = prediccion.summary_frame(alpha=0.05)  # IC al 95%

plt.figure(figsize=(6, 4))
plt.scatter(wage['age'], wage['wage'], alpha=0.2, s=12, color='gray')
plt.plot(age_grid, resumen_pred['mean'], color='darkblue', lw=2,

plt.fill_between(age_grid,
                  resumen_pred['mean_ci_lower'],
                  resumen_pred['mean_ci_upper'],

2.5 Selección del grado del polinomio

2.5.1 Enfoque clásico: prueba F de modelos anidados

Como los modelos de grado \(1, 2, 3, \dots\) son anidados (uno es un caso particular del siguiente), podemos comparar cada par de modelos consecutivos con una prueba \(F\):

\[H_0: \beta_d = 0 \ \text{(el modelo de grado } d-1 \text{ es suficiente)} \qquad \text{vs.} \qquad H_1: \beta_d \neq 0.\]

Código 
modelos = {}
for d in range(1, 6):
    design_d = MS([poly('age', degree=d)])
    X_d = design_d.fit_transform(wage)
    modelos[d] = sm.OLS(wage['wage'], X_d).fit()

tabla_anova = sm.stats.anova_lm(modelos[1], modelos[2], modelos[3],
                                 modelos[4], modelos[5])

Regla de decisión: se recorre la tabla de arriba hacia abajo y se elige el primer grado \(d\) tal que el valor \(p\) de agregar el término \(d+1\) ya no sea significativo (por ejemplo, mayor a 0.05).

Nota

La prueba \(F\) anidada es válida aquí porque los modelos comparados usan exactamente los mismos datos y difieren solo en el grado del polinomio. Si el modelo incluyera otros predictores (por ejemplo, education), la comparación por ANOVA seguiría siendo válida y es preferible a mirar los valores \(t\) individuales de los términos de poly, cuya interpretación aislada no es directa por tratarse de una base ortogonal.

2.5.2 Enfoque moderno: validación cruzada de 10 particiones

Código 
from sklearn.model_selection import KFold
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

X = wage[['age']].values
y_arr = wage['wage'].values

kf = KFold(n_splits=10, shuffle=True, random_state=42)
grados = range(1, 11)
ecm_promedio = []

for d in grados:
    errores_fold = []
    # OJO: usamos 'transformador_poly' y NO 'poly', para no sobrescribir
    # la funcion 'poly' que importamos de ISLP.models mas arriba.
    transformador_poly = PolynomialFeatures(degree=d, include_bias=False)
    for idx_train, idx_test in kf.split(X):
        X_train_poly = transformador_poly.fit_transform(X[idx_train])
        X_test_poly = transformador_poly.transform(X[idx_test])
        modelo_cv = LinearRegression().fit(X_train_poly, y_arr[idx_train])
        pred = modelo_cv.predict(X_test_poly)
        errores_fold.append(mean_squared_error(y_arr[idx_test], pred))
    ecm_promedio.append(np.mean(errores_fold))

d_optimo = list(grados)[int(np.argmin(ecm_promedio))]
print(f'Grado óptimo según validación cruzada: {d_optimo}')
Grado óptimo según validación cruzada: 3
Código 
plt.figure(figsize=(6, 4))
plt.plot(list(grados), ecm_promedio, marker='o')
plt.axvline(d_optimo, color='red', linestyle='--',
            label=f'Grado óptimo = {d_optimo}')
plt.xlabel('Grado del polinomio (d)')
plt.ylabel('ECM promedio (validación cruzada, 10 folds)')
plt.title('Selección del grado por validación cruzada')
plt.legend()
plt.tight_layout()
plt.show()
AdvertenciaConsejo práctico: cuidado con la reutilización de nombres de variables

En el bloque anterior, la variable del transformador polinomial se llama deliberadamente transformador_poly y no poly. Esto es intencional: como poly ya fue importado arriba desde ISLP.models y lo necesitaremos de nuevo más adelante (en la regresión logística), si aquí lo sobrescribiéramos con un objeto PolynomialFeatures de scikit-learn, cualquier código posterior que intente usar poly(...) como función fallaría con un error del tipo:

TypeError: 'PolynomialFeatures' object is not callable

En la práctica, ambos enfoques (ANOVA y validación cruzada) suelen sugerir un grado bajo (2, 3 o 4). Coexisten en la literatura porque ANOVA da una justificación inferencial clásica basada en la teoría de mínimos cuadrados, mientras que la validación cruzada es más robusta cuando no se cumplen exactamente los supuestos de normalidad y homocedasticidad de los errores.

2.6 Extensión: regresión logística polinomial

Ahora convertimos el problema en uno de clasificación binaria: ¿el salario de una persona supera los 250 mil dólares?

Código 
wage['salario_alto'] = (wage['wage'] > 250).astype(int)

design_logit = MS([poly('age', degree=4)])
X_logit = design_logit.fit_transform(wage)
y_logit = wage['salario_alto']

modelo_logit = sm.GLM(y_logit, X_logit, family=sm.families.Binomial()).fit()
summarize(modelo_logit)

Observen que la probabilidad estimada aumenta con la edad hasta alrededor de los 40-50 años y después disminuye, de forma consistente con lo observado en la regresión polinomial de la variable cuantitativa wage.
